功能特性

为本地音频目录准备的播放体验

目录是播放列表的基础，控制与状态则围绕连续收听展开。

≡

播放列表

按目录分组自然排序，支持实时搜索；每首显示总时长与已听进度。

◷

进度记忆

记住每首的上次播放位置与上次播放曲目，刷新或重开后自动恢复。

1×

倍速播放

范围 0.1～4.0，预设 0.5 / 0.75 / 1 / 1.25 / 1.5 / 1.75 / 2 / 2.5 / 3 / 4，并可 ±0.1 微调；选择全局记忆。

↻

播放模式

可在顺序、列表循环、单曲循环与随机之间切换。

字幕与细节操控

同名 .vtt 自动挂载，一键开关；悬浮展示不挤压版面，播放中途开启也可即时跟词。支持 ±15s、5～60 分钟定时停止及空格、←→、↑↓ 快捷键。

◉

Mac 风格与移动端

毛玻璃窗口、交通灯与 60 秒一圈的慢速黑胶唱片；深色模式可自适应。≤899px 整页滚动，越过播放器后顶部显示播放、切集、搜索与倍速迷你控制条。

快速开始

本地 Python 方式

01

创建虚拟环境

uv venv --python 3.13
02

安装依赖

uv pip install -r requirements.txt

仅运行播放器本体只需要 python-dotenv。

03

配置目录

cp .env.example .env

编辑 .env 设置 AUDIO_DIR。路径与端口统一配置，代码不硬编码路径。

04

放入音频

将 .m4a、.mp3、.opus、.ogg、.flac 等文件按任意目录结构放入 AUDIO_DIR（默认 ./audio）；子目录自动成为播放列表分组。

05

启动并访问

python server.py

打开 http://127.0.0.1:8792。可在 .env 改 KAUDIO_PORT；手机同局域网访问 http://<电脑IP>:8792。

部署方式

按你的环境选择

本地 Python

使用 uv 管理 Python 3.13 虚拟环境，配置和启动过程直接在本机完成。

  • • 仅运行播放器本体只需 python-dotenv
  • • AUDIO_DIR、KAUDIO_PORT 等统一放在 .env
  • • 无前端构建步骤

Docker（可选）

docker compose up -d --build
  • • 与本地方式保持一致，镜像内含 ffmpeg，ffprobe 自动可用。
  • • .env 的 AUDIO_DIR 可挂载任意宿主机目录，例如 F:/music。
  • • static/ 以挂卷覆盖进容器，改 HTML/CSS/JS 后刷新页面即可生效，无需 rebuild。
  • • 内置 /api/list 每 30 秒健康检查；docker ps 可见 healthy，restart: unless-stopped 可随 Docker 开机自启。
  • • 时长缓存存于 .cache/docker，删除后会重新探测。

技术细节

少量组件，清晰边界

后端提供静态文件、播放列表与音频 Range 流式传输，拖动进度条可及时响应。config.py 解析 .env 为 settings，是全项目唯一路径来源。

API

接口用途
GET /api/list播放列表，含每首总时长 dur；时长缓存于 .cache/durations.json。
GET /audio/<path>音频流，支持 Range 请求。

.env 配置

变量说明默认
AUDIO_DIR音频目录./audio
KAUDIO_PORT服务器端口8792
FFPROBE_PATHffprobe 路径，用于探测总时长PATH 查找

FAQ

常见问题

支持哪些音频格式？

常见格式均可：.m4a / .mp3 / .opus / .ogg / .flac 等，按目录结构放置即可。

手机上能用吗？

可以。手机与电脑处于同一局域网时，访问 http://<电脑IP>:8792；≤899px 自动切换移动端布局，滚过播放器后顶部吸附迷你控制条。想要不依赖电脑常开的原生应用，可用姊妹项目 local-audio-android——与 Web 版功能对等的 Android 客户端，Releases 提供现成 APK。

字幕怎么挂？

将与音频同名的 .vtt 文件放在同目录即可自动挂载。播放器内可一键开关，字幕悬浮展示，不挤压版面。

必须装 Docker 吗？

不必。仅运行播放器本体只需要 python-dotenv；Docker 是免配环境的可选方式。

播放进度会丢吗？

不会。每首的上次播放位置与上次播放曲目都有记忆，刷新或重开会自动恢复。

端口或目录怎么改？

全部在 .env：AUDIO_DIR 修改音频目录，KAUDIO_PORT 修改端口；config.py 统一解析，代码没有硬编码路径。
